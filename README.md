# 🍕 Rasa Custom Workspace Dashboard

An interactive, custom-built workspace dashboard for managing and testing Rasa conversational bots. This interface allows you to add/remove intents safely without corrupting YAML files, trigger model retraining locally, and talk to your trained model in real-time.

## 🛠️ Tech Stack
* **Conversational AI Framework:** Rasa (`v3.6.21`)
* **Dashboard Interface:** Gradio (`v6.19.0`)
* **Strict Round-trip Parser:** ruamel.yaml (`v0.17.21`)
